## Component Inventory

### New component: MarkSelector

A horizontal group of 4 selectable chips placed inside the existing setup card, below the topic grid and above the "Generate Exercise" button.

**Location:** Inline in `app/listening/page.tsx` (or extracted to `components/listening/MarkSelector.tsx` if preferred by executor).

**Chips:** Four options — 5, 10, 15, 25 marks. Default selected: 10.

**Selected chip appearance** (mirrors existing topic button selected state):
```
border-sky-400/50 bg-gradient-to-br from-sky-400/20 via-sky-500/10 to-zinc-950
text-white shadow-[0_20px_45px_-30px_rgba(56,189,248,0.95)]
```

**Unselected chip appearance** (mirrors existing topic button unselected state):
```
border-white/10 bg-gradient-to-br from-zinc-800 via-zinc-900 to-zinc-950
text-zinc-200 hover:border-sky-400/25 hover:text-white
```

**Chip layout:** `grid grid-cols-4 gap-2` — four equal-width chips in a single row.

**Chip content:** Mark number in large text (text-sm font-semibold), label "marks" in text-[10px] uppercase tracking-wide zinc-500 below it.

**State indicator:** Same 10px dot in top-right corner as topic buttons — `bg-sky-300 shadow-[0_0_0_6px_rgba(125,211,252,0.13)]` when selected, `bg-zinc-600` when not.

**Section eyebrow:** Add a second eyebrow above the chips:
```
<p className="text-[11px] font-semibold uppercase tracking-[0.22em] text-sky-300/70">Mark Target</p>
<h2 className="text-lg font-semibold text-white">How many marks?</h2>
<p className="text-sm text-zinc-400">Total marks determines how many questions are generated.</p>
```

## Interaction Contract

### Mark selector behavior

| Interaction | Result |
|-------------|--------|
| Page loads | 10-mark chip is selected by default |
| User clicks a chip | That chip becomes selected; others deselect |
| User clicks "Generate Exercise" | `marks` value (5/10/15/25) is included in POST body to `/api/listening/generate-script` |
| Loading state | All chips disabled (`pointer-events-none opacity-60`) while `loading === true` |

### Generate Exercise button

No change to existing button appearance or loading state. The only change is that the API call now includes `marks` in the request body.

### Error state

Error text for generation failure uses existing pattern: `text-xs text-red-400` rendered inline below the chips, above the CTA button. Copy: "Generation failed — check your connection and try again."
